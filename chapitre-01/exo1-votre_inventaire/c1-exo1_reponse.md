## 1. Ce que je sais / mes représentations actuelles

### API graphiques connues
* **Vulkan / OpenGL :** API bas niveau et cross-plateforme.
* **DirectX (11/12) :** API graphique de Microsoft.
* **Metal :** API graphique dédiée à l'écosystème Apple.

### Rôle et fonctionnement
* Interface entre le processeur (CPU) et le processeur graphique (GPU).
* Gestion du pipeline de rendu (envoi de vertices, gestion des shaders, rastérisation).
* Contrôle des buffers d'affichage (framebuffer, depth buffer).

### Ce que j'ai déjà essayé ou implémenté
* Création de fenêtres de rendu et contextes d'affichage.
* Écriture de shaders basiques (Vertex et Fragment Shaders).
* Tests sur des architectures de moteurs 2D/3D.
